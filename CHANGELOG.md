# Changelog

All notable changes to this project are documented in this file, collated
automatically from `changelog.d/` fragments by the release gate at merge time.

## Versioning

- `major`: a breaking change to the public contract (`src/index.ts`'s exports, the config schema, or the graph JSON schema).
- `minor`: a backward-compatible addition (a new optional field, a new export).
- `patch`: a fix with no schema or contract change.
