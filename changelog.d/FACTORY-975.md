### Added
- Agent-status pulse animation on the seer canvas (`public/agent-animation.js`, `public/style.css`): WORKING nodes pulse their own fill shape (`path.node-shape`) inward (scale 1 -> 0.9, 2.4s, ease-in-out); STALLED and BLOCKED nodes instead pulse the Jira-status border (`path.node-border-ring` + `path.node-border-gap`) outward — STALLED scale 1 -> 1.12 over 1.6s, BLOCKED scale 1 -> 1.2 over 0.9s with a slightly thicker stroke at its peak (3.5px -> 4.5px). idle/none/unrecognized stays static. Pure CSS `@keyframes` + `transform: scale()` (`transform-box: fill-box; transform-origin: center`) — no JS render loop drives it; `public/app.js` only toggles the class per node (on every render pass, so a status change on refresh swaps the class in place) and a deterministic per-node `--pulse-delay` stagger (hash of the node id, `public/agent-animation.js`'s `staggerDelayMs`) so nodes don't pulse in lockstep.
- `prefers-reduced-motion: reduce` disables all three pulse animations outright.
- A "Pulses: on/off" toggle button in the left sidebar header (`#animation-toggle`), persisted via `public/animation-prefs.js`'s `loadAnimationsEnabled`/`saveAnimationsEnabled` (localStorage, wrapped in try/catch — degrades to "enabled" when storage is unavailable or throws).
